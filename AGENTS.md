# Checkdrop product and UI rules

- Production UI must look deliberately designed for Checkdrop, not assembled from generic AI-generated patterns.
- Do not use decorative colored rails or accent strips on repeated cards, gratuitous gradients, glows, glassmorphism, ornamental icons, or oversized pill decoration.
- Communicate state with concise Czech copy, semantic labels, familiar icons, typography, spacing, and neutral structure. Add color only when it carries necessary meaning and is not duplicated elsewhere.
- Prefer compact, information-dense layouts suitable for hundreds or thousands of customer records.
- Visually verify every production UI change at desktop and mobile widths before calling it complete.
