# Checkdrop web design notes

- Preserve the calm dark review-canvas composition, narrow icon rail, compact field rows, explicit
  evidence, and the three-step review flow.
- Keep visible claims source-backed. Do not add confidence percentages, pilot KPIs, or capabilities
  that the backend does not yet provide.
- Use the shared Astro app for future marketing, documentation, playground, and dashboard routes;
  do not split them into separate frontend projects.
- Product icons come from `@phosphor-icons/react`. Do not replace them with emoji, handcrafted SVG,
  CSS drawings, or text glyphs.
